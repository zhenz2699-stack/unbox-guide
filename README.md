# 搬瓦工搭建个人专属网络指南

用一台搬瓦工 VPS 搭建自己的网络通道，全流程图文教程，按步骤做即可。

## 目录

- [Mac 版指南](mac-guide.md) —— 客户端使用 Hiddify
- [Win 版指南](win-guide.md) —— 客户端使用 v2rayN

## 内容概览

两个版本流程基本一致：

1. 购买搬瓦工 VPS（新账号有 30 天全额退款保障）
2. 获取服务器连接信息，重装 Ubuntu 22.04 系统
3. 用终端 / PowerShell 连接服务器
4. 一键安装 VLESS + Reality 协议
5. 配置客户端
6. 多人使用：给每个人单独生成专属链接，随时增删

搭建过程中卡住了，直接把报错截图丢给任意 AI 助手，基本都能解决。
