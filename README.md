电脑下载 WorkBuddy、QoderWork 或者其他本地 AI，直接把对应你电脑的链接发给 AI 就可以直接安装。如果不知道自己适合哪款，可以在[搬瓦工选型参考](https://unboxvps.com/)选择合适自己的。

## 内容概览

新手购买 VPS 后，下一步应该怎么做？

购买 VPS 后，很多新手不知道如何连接服务器、查看服务器信息、更新系统、配置基础安全环境。为了方便不同系统用户快速上手，我们整理了 Mac 和 Windows 两个版本的 VPS 入门操作指南。

这两份指南主要适合用于：

- 学习如何通过 SSH 连接 VPS
- 熟悉搬瓦工 KiwiVM 控制面板
- 了解服务器 IP、端口、root 密码等基础信息
- 完成 Ubuntu 系统更新
- 做好基础防火墙和安全配置
- 为后续部署网站、博客或个人项目做准备

你可以根据自己的电脑系统选择对应教程：

- [Mac 版指南](mac-guide.md)（macOS 用户）
- [Win 版指南](win-guide.md)（Windows 用户）

搭建过程中卡住了，直接把报错截图丢给任何 AI 助手，基本解决。

> **提醒**：VPS 应用于个人网站、博客部署、开发测试、远程运维学习、数据备份等合规场景。请遵守所在地法律法规、服务商使用条款以及相关平台规则。
